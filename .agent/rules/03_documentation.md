# ドキュメント

## ドキュメントの作成

- このリポジトリには docs サイトはありません。ドキュメントは Markdown で、以下に置いています。
  - `README.md` - ライブラリの概要、Install、Quick start、画像 (`hagaki/pending-images`)、Client API、CLI、配信 worker、Entry points、開発手順
  - `sample/README.md` - コンテンツフォーマット (ディレクトリレイアウト、frontmatter、カテゴリ、生成物) の定義
  - `template/README.md` と `template/*/README.md` - テンプレートの使い方と deploy 手順
- コードを記述した後に、公開 API・entry point・CLI・コンテンツフォーマットに変更があれば、該当する README を作成または追記してください。
- なお、文章の文体について、その他の部分で支持があったとしても、ドキュメントに関しては、あくまでも文章の文体で記載してください。
- 既存の README は日本語の常体 (「〜する」「〜を使う」) で書かれているので、それに合わせてください。
